4) WORKFLOW GITHUB "Cerbero (apprendimento)"
-----------------------------------------------
File: .github/workflows/cerbero_learn.yml — SOLO workflow_dispatch, nessun
cron. Input `modalita`: osservazioni | trasversale | entrambi | storico.
 - osservazioni: impara soglie da osservazioni live, scrive JSON (serve secret
   Sorare freschi + righe mature).
 - trasversale: distribuzione rendimento per fascia margine, non scrive JSON.
 - entrambi: osservazioni poi trasversale (trasversale solo se la prima ok).
 - storico: bootstrap offline dal dataset storico, zero query, sempre disponibile.
Output: docs/handoff/LEARN_<modalita>_<data_ora>.txt + artifact 30gg. Commit
automatico del JSON soglie solo per osservazioni/storico/entrambi.
Se 403/secret scaduti: messaggio esplicito in log "SECRET SORARE SCADUTI...".
Come lanciarlo: GitHub -> Actions -> "Cerbero (apprendimento)" -> Run workflow
-> scegli modalita -> Run workflow (branch main).
MAI lanciato su GitHub finora: attende l'ok utente.
