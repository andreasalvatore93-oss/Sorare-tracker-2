4) WORKFLOW "Cerbero (apprendimento)" — come si usa
-------------------------------------------------------
File: .github/workflows/cerbero_learn.yml. Solo lancio manuale (nessun
cron). Un input a tendina, `modalita`, con 4 scelte:
 - osservazioni: legge le righe mature del CSV, impara le soglie per lega e
   RISCRIVE cerbero_soglie_apprese.json. Serve secret Sorare validi + righe
   gia' mature (vedi §3).
 - trasversale: stampa solo un report (rendimento per fascia di margine),
   NON scrive nulla. Diagnostico.
 - entrambi: prima osservazioni, poi trasversale (se la prima riesce).
 - storico: bootstrap offline dal dataset storico, zero query, funziona
   sempre anche a secret scaduti.
Output: file docs/handoff/LEARN_<modalita>_<data_ora>.txt committato in
automatico + artifact scaricabile (30gg). Se i secret sono scaduti, il log
lo dice esplicitamente ("SECRET SORARE SCADUTI").

PASSO PASSO per lanciarlo dal sito GitHub (usare quando l'utente e' pronto):
 1. github.com -> repo Sorare-tracker-2 -> scheda "Actions".
 2. Colonna sinistra -> "Cerbero (apprendimento)".
 3. Bottone "Run workflow" in alto a destra della lista run.
 4. Branch: main (default). Menu "cosa lanciare": scegliere "osservazioni".
 5. Bottone verde "Run workflow".
 6. Aspettare qualche secondo, ricomparira' una riga con pallino giallo (in
    corso) -> giallo diventa verde (ok) o rosso (errore) in pochi minuti.
 7. Risultato: aprire docs/handoff/LEARN_osservazioni_*.txt nel repo, oppure
    chiedere a Claude di leggerlo e riassumerlo.
