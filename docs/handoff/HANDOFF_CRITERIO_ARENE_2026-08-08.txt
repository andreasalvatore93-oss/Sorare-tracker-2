3. COSA HO TOCCATO -- COME SI RILANCIA
=====================================================================
In generate_arene_efficienti, ogni tipo produce ancora 'resa' (essenze
attese, come sempre). Con ARENA_CRITERIO='capitale' il CONFRONTO fra tipi
usa resa/COSTO_INGRESSO[tipo] invece di resa nuda; la resa vera (essenze) e'
comunque quella che entra nella formazione scelta, il criterio cambia solo
QUALE tipo si sceglie a ogni passo. Il criterio di stop resta "il migliore
possibile non rende piu' niente" (matematicamente equivalente in entrambi i
casi, verificato: COSTO_INGRESSO e' sempre positivo, quindi dividere non
cambia il segno).

Rilancio locale (nessuna query se non serve il top-up L10, che gira solo
con SORARE_COOKIE impostato):

Rilancio GitHub Actions (formazione_giornata.yml), nuovo input arena_criterio:
  gh workflow run formazione_giornata.yml -f arena_criterio=capitale -f escludi_lockate=1 -f arene=N ...
