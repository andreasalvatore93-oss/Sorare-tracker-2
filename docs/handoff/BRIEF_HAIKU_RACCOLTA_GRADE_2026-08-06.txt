===============================================================================

non solo sulle carte possedute:

  query { anyPlayer(slug: $slug) {
      playerGameScores(last: 15) {
        id score anyGame { date }

I campi aggiuntivi (minuti, quote) sono gia' recuperati nel filone: guarda
p12_lettera_grade.py e i file p12_r1_minuti.json / p12_r5_gk_ampio.json per i
