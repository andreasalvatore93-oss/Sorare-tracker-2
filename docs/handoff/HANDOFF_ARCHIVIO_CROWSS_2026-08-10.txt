Come si rilancia un'estrazione su un'altra GW (rete, qualche minuto):
  1. python -c "..." con ricostruisci_manager.partecipazioni('crowss', '<fixture_slug>')
     (serve SORARE_COOKIE in env per l'indice; le formazioni sono pubbliche)
  2. Per ogni contender, ricostruisci_manager.formazione(slug) -> carte/piazzamento
  3. Controllo coerenza: somma punteggi carte vs punteggio ufficiale, tolleranza 0.5
     -> se scarto grande, annullata (vedi README per trattamento arena/Da7)
  4. Costruire l'input {slug: {ruolo, dir}} con analisi_manager/analizza_gw.indice_lega()
     per gli slug SENZA atteso, poi predici_manager_batch.py --input <file> --force
  5. Ricalcolare score_atteso (backtest_arene_previsioni.py) con la cache aggiornata
  6. Scrivere i JSON secondo lo schema in archivio_crowss/README.md
